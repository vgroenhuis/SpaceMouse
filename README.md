# SpaceMouse Controller

The SpaceMouse controller is a Teensy 4.1 microcontroller which translates raw SpaceMouse input data (values of six axes, plus buttons) to Mamri protocol messages. The SpaceMouse typically controls a Sunram7 biopsy robot.
